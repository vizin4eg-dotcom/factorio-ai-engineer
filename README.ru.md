# Factorio AI Engineer 🏭🤖

[English](README.md) | [Русский](README.ru.md)

Автономный ИИ-агент, играющий в **Factorio 2.0 (Space Age)** в реальном времени с использованием больших языковых моделей (Gemini / OpenAI API / локальные LLM через Kobold.cpp).

В отличие от подходов, основанных исключительно на компьютерном зрении (Computer Vision), данный проект использует высокоточную **пространственную систему координат**, интерактивное сканирование окружения и гибридную архитектуру очереди задач. Агент исследует окружающие объекты, анализирует рецепты крафта и свой инвентарь, после чего возводит работающие автоматизированные производственные цепочки прямо на карте.

---

## 🌟 Ключевые возможности и улучшения

- **Пространственный координатный движок**: Специальные игровые операции мода (`walk_to(x, y)`, `place_entity(name, x, y, dir)`, `move_items(..., x, y)`), позволяющие манипулировать объектами с субтайловой точностью вместо слепого преследования целей.
- **Сканирование окружения и позиции игрока (`scanEntities`)**:
  - Динамический радар, возвращающий точные мировые координаты `(x, y)` ближайших объектов.
  - Автоматически определяет и возвращает координаты игрока (`player.x`, `player.y`), позволяя строить здания относительно текущей позиции (например, «к востоку от меня»).
  - Кластеризация и фильтрация ресурсов (сжимает огромные рудные пятна из 10 000+ токенов в компактные опорные точки, экономя контекст модели).
- **Стандарт направлений Factorio 2.0**: Полная поддержка 16-позиционной розы ветров (Север: `0`, Восток: `4`, Юг: `8`, Запад: `12`).
- **Автономное мышление и многошаговые очереди задач**:
  - Автоматическая проверка инвентаря и крафт недостающих компонентов перед началом строительства.
  - Последовательное выполнение задач в очереди игрового тика (например: *Скрафтить печи -> Подойти -> Поставить в ряд -> Заправить углём*).
- **Безопасная динамическая классификация сущностей**: Встроенный словарь для естественных понятий (`tree`, `rocks`, `ore`, `enemy`) с защитой от вылетов сервера при получении неизвестных названий.
- **Скрытое выполнение команд (`/sc`)**: Чистый игровой чат без спама служебными командами сервера.
- **Поддержка облачных и локальных моделей**: Работает «из коробки» с Gemini 2.5 Flash / Flash-Lite через OpenAI-совместимый интерфейс, а также с локальными инференс-серверами (Kobold.cpp / Ollama).

## 🚀 Быстрый старт

### 1. Требования
- **Factorio** (рекомендуется версия 2.0+)
- **Node.js** (v22+ или v24+) и пакетный менеджер **pnpm**
- **Docker Desktop** (для запуска HTTP-шлюза к RCON)

### 2. Установка мода
Скопируй папку мода в каталог модов сервера и клиента:
```cmd
xcopy /E /I packages\autorio C:\Games\FactorioHeadless\mods\autorio
:: Также скопируй в папку модов игрового клиента:
xcopy /E /I packages\autorio %appdata%\Factorio\mods\autorio
```
*(Убедись, что в папках mods нет конфликтующих архивов `autorio_*.zip`).*

### 3. Запуск шлюза RCON API (Docker)
Запусти собранный Go-контейнер для трансляции RCON в HTTP:
```bash
docker run --rm -it --name factorio-rcon-api \
  -e FACTORIO_RCON_HOST=127.0.0.1 \
  -e FACTORIO_RCON_PORT=27015 \
  -e FACTORIO_RCON_PASSWORD=your_rcon_password \
  -p 24180:24180 \
  factorio-rcon-api:local
```

### 4. Запуск сервера Factorio и обёртки
В корневой папке проекта:
```bash
pnpm --filter ./packages/factorio-wrapper run dev
```

### 5. Настройка и запуск ИИ-агента
Создай файл `packages/agent/.env.local`:
```env
OPENAI_API_KEY=your_api_key
# Примеры:
# Gemini: [https://generativelanguage.googleapis.com/v1beta/openai/](https://generativelanguage.googleapis.com/v1beta/openai/)
# OpenRouter: [https://openrouter.ai/api/v1/](https://openrouter.ai/api/v1/)
# Локально (Kobold.cpp): [http://127.0.0.1:5001/v1/](http://127.0.0.1:5001/v1/)
OPENAI_API_BASEURL=your_api_base_url

RCON_API_SERVER_PORT=24180
RCON_API_SERVER_HOST=127.0.0.1

FACTORIO_WS_PORT=8080
FACTORIO_WS_HOST=127.0.0.1
```

Запусти агента:
```bash
cd packages/agent
pnpm dlx tsx --env-file=.env.local src/main.ts
```

## 💬 Примеры команд в игровом чате

Подключись к серверу (`127.0.0.1:34197`) и напиши в чат:

- **Оценка обстановки:**
  > *"Scan area with radius 10 and tell me what you see"*
- **Автономный крафт и строительство:**
  > *"Check my inventory. If I have less than 3 stone furnaces, craft what is needed. Then scan the area and place 3 stone furnaces in a row starting 2 tiles east of my position."*
- **Сборка производственной ячейки:**
  > *"Place 1 burner mining drill at -76.5, -108.5 facing south, place 1 stone furnace at -76.5, -106.5, and put 5 coal into both."*
- **Сбор конкретных ресурсов:**
  > *"Cut 5 trees around you"*
